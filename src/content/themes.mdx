Picobel comes with a few pre-made themes (for times when you don't want to style an entire audio player from scratch). To use a theme, make sure you've downloaded the correct stylesheet from the [Picobel CSS library](https://github.com/tomhazledine/picobel/tree/main/packages/picobel/src/css) and then reference the chosen theme name as an option when you initialize Picobel in your JS.

```html
<!-- Load the theme's stylesheet -->
<link
    rel="stylesheet"
    href="https://cdn.jsdelivr.net/npm/picobel@3/build/picobel.default.css"
>

<!-- Initialise Picobel with a theme -->
<script>
    picobel( { theme: "default" } );
</script>
```

You can find the CSS files for each theme in the [`/packages/picobel/src/css` directory of the GitHub repo](https://github.com/tomhazledine/picobel/tree/main/packages/picobel/src/css), along with minified production-ready versions [here](https://github.com/tomhazledine/picobel/tree/main/packages/picobel/build). The filename convention is `picobel.THEME_NAME.css`.

## Themes currently supported by **Picobel v3**:

* **Default**: [`picobel.default.css`](https://cdn.jsdelivr.net/npm/picobel@3/build/picobel.default.css)
* **Skeleton**: [`picobel.skeleton.css`](https://cdn.jsdelivr.net/npm/picobel@3/build/picobel.skeleton.css)
* **iTunes**: [`picobel.itunes.css`](https://cdn.jsdelivr.net/npm/picobel@3/build/picobel.itunes.css)
* **BBC**: [`picobel.bbc.css`](https://cdn.jsdelivr.net/npm/picobel@3/build/picobel.bbc.css)
* **Soundcloud**: [`picobel.soundcloud.css`](https://cdn.jsdelivr.net/npm/picobel@3/build/picobel.soundcloud.css)
* **Pitchfork**: [`picobel.pitchfork.css`](https://cdn.jsdelivr.net/npm/picobel@3/build/picobel.pitchfork.css)
* **Eaten by Monsters**: [`picobel.eatenbymonsters.css`](https://cdn.jsdelivr.net/npm/picobel@3/build/picobel.eatenbymonsters.css)

You can see them all in action in the [Picobel.js CodePen Collection](http://codepen.io/collection/XpZEor/), and see screenshots of each featured theme on this page:

### Default

![Default theme](/images/theme_basic.png)

_[View this theme on CodePen](http://codepen.io/tomhazledine/pen/VpNqYO)_

The default theme. The highlight colour can be altered by overriding the `--highlight` CSS custom property:

```css
.picobel {
    --highlight: "red";
}
```
